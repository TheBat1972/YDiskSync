# YDiskSync — Яндекс Диск на Маке

Маленькая программа для строки меню: держит выбранные папки Яндекс Диска в обычной папке на вашем Маке.
Положили файл туда — он появился на Диске. Изменили на Диске — обновился на Маке.

Работает на Apple Silicon и Intel, macOS 11 и новее. В Dock значка нет — только значок в строке меню.

## Как собрать

Нужен Xcode или Command Line Tools. В Терминале:

```bash
cd ~/prog/YDiskSync
./build.sh
```

Получится `YDiskSync.app`. Перетащите её в «Программы» и запустите.

## Как настроить (один раз, 5 минут)

**1. Заведите приложение на Яндексе (для теста этого достаточно)**

1. Откройте <https://oauth.yandex.ru/> и войдите в свой аккаунт.
2. Нажмите «Создать приложение» и выберите **«Для доступа к API или отладки»**.
3. Название — любое, например `YDiskSync`.
4. В правах («Яндекс Диск REST API») отметьте:
   - доступ к информации о Диске,
   - чтение всего Диска,
   - запись в любое место на Диске.
5. Нажмите «Создать приложение». На странице приложения скопируйте **ID приложения** (Client ID).

**2. Получите токен**

1. Откройте в браузере ссылку, подставив свой ID:
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_ID`
2. Разрешите доступ. Яндекс покажет страницу с токеном — скопируйте его.
   (Кнопка «Открыть страницу входа» в программе открывает ту же ссылку.)

**3. Настройте программу**

При первом запуске откроется окно настроек.

1. Вставьте токен и нажмите «Подключить». Сразу откроется окно выбора папок.
2. В окне «Что синхронизировать» программа покажет содержимое вашего Диска:
   - отметьте **«Весь Диск (корень)»** — синхронизируется всё;
   - или отметьте **только нужные папки** (раскрываются стрелочкой).
   Нажмите «Готово».
3. «Выбрать…» — укажите папку на Маке, куда складывать файлы. Лучше создать отдельную, например `~/Яндекс Диск`.
4. Нажмите «Сохранить и синхронизировать».

Токен действует около года; когда он перестанет работать, в меню появится ошибка — получите новый тем же способом.

## Как пользоваться

Значок в строке меню показывает состояние:

- обычный значок — всё синхронизировано;
- **вращающиеся стрелки с процентами** — идёт синхронизация;
- значок с восклицательным знаком — ошибка (текст ошибки в меню и в журнале);
- пауза — синхронизация приостановлена.

По клику открывается меню:

- **Журнал синхронизации…** — окно с ходом работы: полоса прогресса и лента событий (таймлайн): что скачано, загружено, удалено, где конфликт или ошибка.
- **Корзина Диска…** — что лежит в корзине Яндекс Диска (в том числе то, что вы удалили на Маке): можно восстановить выбранное, удалить навсегда или очистить корзину целиком. Восстановленное вернётся и в папку на Маке.
- **Создать ссылку на файл…** — выберите файл или папку внутри папки синхронизации: публичная ссылка создаётся и сразу копируется в буфер обмена.
- **Публичные ссылки…** — список всех ваших ссылок: скопировать, открыть, закрыть доступ.
- **Открыть папку на Маке** — быстро открыть папку в Finder.
- **Синхронизировать сейчас** — не ждать расписания.
- **Приостановить / Возобновить** — временно выключить синхронизацию.
- **Настройки…** — сменить папку на Маке, выбрать другие папки Диска, интервал, запуск при входе в систему.

Изменения в папке на Маке отправляются на Диск **сразу** (в пределах пары секунд). Диск проверяется раз в несколько минут (по умолчанию 5) — так программа замечает изменения, сделанные в других местах.

## Ссылки на файлы

Три способа поделиться файлом:

1. Меню в строке меню → «Создать ссылку на файл…» (⌘K).
2. В Finder: правый клик по файлу в папке синхронизации → «Службы» → «Ссылка Яндекс Диска». Ссылка копируется в буфер обмена, придёт уведомление.
   Программа включает этот пункт сама при первом запуске. Если его всё же нет: в настройках программы нажмите «Включить «Ссылка Яндекс Диска» в меню Finder» или откройте «Системные настройки» → «Клавиатура» → «Сочетания клавиш» → «Службы» → «Файлы и папки» и поставьте галочку.
3. Меню → «Публичные ссылки…» → «Создать ссылку…».

Файл должен уже быть на Диске: только что созданный сначала дождитесь загрузки. Закрыть доступ можно в окне «Публичные ссылки».

## Что нужно знать

- **Структура одинаковая.** Папка `Документы` с Диска окажется как `<ваша папка>/Документы`.
- **Что удаляется на Диске.** Только то, что вы сами удалили на Маке: файл или папка уйдёт в корзину Диска.
  Если удалить что-то на Диске, на Маке оно тоже уйдёт в Корзину.
- **Убрали папку из синхронизации** (сняли галочку в настройках) — её копия на Маке удаляется (в Корзину), а **на Диске ничего не меняется**.
- Если разом нужно удалить очень много файлов, программа остановится и спросит подтверждение в меню — защита от случайной беды.
- **Конфликты.** Если файл изменили и тут, и там, на Маке останется копия «имя (конфликт дата).расширение», а основной файл станет версией с Диска. Ничего не теряется.
- Скрытые файлы (начинаются с точки), временные файлы Office (`~$…`) и ссылки-алиасы не синхронизируются.
- Токен хранится в связке ключей macOS. При пересборке с ad-hoc подписью система может заново спросить доступ — нажмите «Всегда разрешать».

## Из чего состоит

```
Sources/main.swift             запуск, меню, возврат из браузера после входа
Sources/StatusController.swift значок и меню в строке меню
Sources/SettingsView.swift     окно настроек и окно выбора папок Диска
Sources/LinkService.swift      создание публичных ссылок, пункт в меню Finder
Sources/LinksView.swift        окно «Публичные ссылки»
Sources/TrashView.swift        окно «Корзина Диска»
Sources/ActivityLog.swift      журнал событий и прогресс
Sources/ActivityView.swift     окно «Журнал синхронизации» (таймлайн)
Sources/SyncEngine.swift       сама синхронизация
Sources/YandexAPI.swift        запросы к API Яндекс Диска
Sources/FolderWatcher.swift    слежение за папкой на Маке
Sources/OAuth.swift            вход через Яндекс
Sources/Settings.swift         настройки и связка ключей
Tools/make_icon.swift          рисует иконку при сборке
```
